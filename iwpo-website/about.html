它是什么

I wanna play online（简称 iwpo 或 po）本身不是一个游戏，而是一个转换器： 它把用 GameMaker 制作的 I wanna 同人游戏改写成可以多人在线同时游玩的版本。

转换后的游戏里，同一个房间的玩家能看到彼此的位置、共享存档、聊天、互相在屏幕上标记路线。 下面按「转换 → 进入游戏 → 功能 → 限制 → 项目背景」的顺序把它讲清楚。

使用方法：把游戏转换成联机版

  1. 从下载页取得 iwpo 并解压。
  2. 找到你想转换的游戏的 exe 文件——只拖 exe，不是整个文件夹；转换期间请确保该游戏没有在运行。
  3. 把这个 exe 拖到 iwpo.exe 上，等待一段时间。窗口里出现 Success 后按回车结束。
  4. 在原游戏所在的目录里得到转换结果：GameMaker 8 的游戏是带 _online 后缀的 exe；GameMaker Studio 的游戏如果只有一个 exe，会得到带 _online 后缀的文件夹；如果游戏目录里已有 data.win，则直接改写它，原文件备份为 data_backup.win。

如果没有出现 Success，而是报错或闪退，说明这个游戏目前转不了，详见后面的「注意事项」。

进入游戏

第一次启动转换后的游戏，会询问两样东西（各最长 20 个字符）：

  • 名字：给其他玩家看的名字，留空则显示为 Anonymous。
  • 密码：相当于房间号。使用同一个联机包、同一个服务器、同一个密码的玩家会进入同一个房间；留空则进入对所有人开放的公共房间。

这两样只需输入一次，之后会被永久记住，不用每次启动都重输；想换名字或换房间，在游戏内菜单里改即可。 之后像平常一样选存档、选难度进入游戏，就能看到同房间其他玩家的位置和动向了。

特色功能

转换后的游戏会在原游戏之上多出以下功能（提到的按键均为默认值，全部可以改绑）：

  • 共享存档与存档历史：同一房间共享最新存档，一人通过、其他人都能跟上；历史存档可以收藏、用数字键快速读取、随时回滚到之前的状态。
  • 游戏内聊天：按 空格 输入，回车发送。界面、聊天与输入完整支持中文。
  • 标记系统：长按 H 打开轮盘，可放置图标、画折线箭头、手绘或写文本；画布模式适合直接在屏幕上讲解路线。
  • 皮肤系统：在菜单里给自己换装，别人没下载过的皮肤会自动下载；皮肤库见皮肤页。
  • 队伍系统：按队伍区分玩家颜色，方便分组合作或对抗。
  • PVP 子弹共享：在支持的游戏里子弹互通，可以互相伤害。
  • 旁观模式：长按 Y 约 1 秒进入或退出，观察其他玩家进行游戏。
  • 游戏评分：给玩过的游戏打分，评分汇总在本站评分页。
  • 键位全自定义：上面所有按键都能在游戏内设置里改绑。

注意事项

iwpo 支持用 GameMaker 8.0 / 8.1 / 8.2 和 GameMaker Studio 1.x / 2.x（含 x64）制作的游戏， 这覆盖了绝大多数 iw 同人游戏；其他引擎制作的游戏不在支持范围内。

不是每个游戏都能转换。转换失败时程序会明确报错并说明原因；一些加壳、混淆等保护性较强的游戏，目前仍可能转换失败。

联机体验受你的网络质量和服务器状态影响，延迟和掉线都可能发生。 本站大厅页能看到当前在线的房间和人数。

常见问题

断线了怎么办？

断线后游戏会自动重连（最多 10 次）。仍然失败时会提示「离线 - 打开菜单可重连」， 按 O 打开设置面板点「立即重连」即可，不必退出游戏。 也可以在设置里选择连接失败时的行为：留在游戏里离线继续玩，或者直接退出。

名字或密码想改？

游戏内菜单里随时可以改，不需要重新转换。

转换时报错、没有 Success？

说明这个游戏目前无法转换，报错信息会给出原因。

遇到问题去哪里反馈？

请到 GitHub Issues 提交，写明游戏名、IWPO 版本和复现步骤；转换失败的话附上转换器的完整输出。

技术说明

转换器读取游戏文件本身的资源结构，找到人物对象、存档脚本与事件代码，再把联机模块注入进去： GM8 系直接改写 exe 资源块，GMS 系改写 data.win（x86 与 x64）。 本站是纯静态页面，大厅与评分等实时数据来自同机容器中的 API 服务； 联机服务器使用 TCP 8002（游戏数据与聊天）与 UDP 8003（实时位置同步）两个端口。

项目历史

I wanna play online 先后有三条开发线：DapperMink 的原版（2019 – 2022）、TheBiob 在原版基础上延续的 1.1.10 测试版分支（2023 – 2026），以及本站发布的 1.2.3（2026 年起，以 1.1.9 为基础重写）。

  • 2019-12-22
    项目创建

    DapperMink（QuentinJanuel）在 GitLab 建立 i-wanna-play-online/modder，2020-01-01 首次提交，01-11 写出 GM8 转换器的第一版。随后建立联机服务端与网站（01-13）、基于 krzys-h 的 UndertaleModTool 的 GameMaker Studio 转换器 modder-gms（01-18），并于 01-19 加入 UDP 位置同步。

  • 2020-01-24
    1.0.0 发布

    首个公开版本。次日连发 1.1.0 – 1.1.3：加入房间密码，并集中修复首发暴露的问题。联机服务器最初托管在 isocodes.org。

  • 2020-02
    1.1.4 – 1.1.5 · 首批社区贡献

    hirtown 贡献自定义端口（01-27 合入）；Nikaple 贡献 Nikaple 引擎支持、存档共享与移动连续性改进（1.1.4，02-01）。1.1.5 加入心跳与竞速模式（Race mod），修复大型 GM8 游戏的内存溢出，带密码的房间不再显示在网站上。

  • 2021-06-02
    1.1.6 · 更换服务器

    联机服务器由 isocodes.org 迁至 dappermink.com。

  • 2022-01 → 02
    1.1.7 – 1.1.9 · 原版的最后一轮更新

    Samiboule 修复文本编码（1.1.7），加入 GM8.2 支持与 Renex 引擎兼容（1.1.8）；Nikaple 加入 GM8.0 聊天的中文（Unicode）支持（1.1.9，2022-02-27）。1.1.9 是原版仓库的最后一个版本；2024-02 原作者为服务端与网站加上了 Docker 部署，此后原版没有再更新。

  • 2023 → 2026
    TheBiob 分支 · 1.1.10 b1 – b23

    TheBiob（2020 年起为原版提交修复）在 gitlab.com/TheBiob/modder 延续原版代码，陆续发布 23 个测试版：命令行参数与 INI 配置、mod 框架（b13，2024-03）、断线自动重连（b18，2024-12）、自动更新工具（b23，2026-06-20）等；gaphodil 为它的 mod 框架编写了 mod 集合 iwpo-mods（2026）。

  • 2026-04-14
    1.2.3 beta 1 – 5 · 本项目

    以 1.1.9 为基础重写：beta 1 – 3（04-14 – 04-17）带来队伍、存档历史、观战、聊天记录、评分、键位自定义与中文显示；beta 4（05-03）加入共享进度同步、标记轮盘与五页设置面板；beta 5（05-28）加入快速读档并加固兼容性。

  • 2026-07 → 09
    1.2.3 beta 6

    六页设置菜单、界面多语言（默认简体中文）、皮肤系统与服务器皮肤库、标记系统、PVP 子弹与多玩家对象；开发中参考了 TheBiob 分支的部分做法，例如独立的联机 world 对象与读档流程。
